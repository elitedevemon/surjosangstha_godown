## দ্রুত শুরু (Quick Start)

**নিজের কম্পিউটারে দেখতে চাই:**
1. Node.js 20+ ও XAMPP ইনস্টল → [local.md ধাপ ১](./local.md#১-সফটওয়্যার-ইনস্টল)
2. `npm install`
3. XAMPP-তে `ss_db` ডাটাবেস বানান
4. `.env` ফাইল বানান
5. `npx drizzle-kit push --force`
6. `npx tsx src/db/seed-cli.ts --force`
7. `npm run dev` → http://localhost:3000

**ফ্রিতে ইন্টারনেটে লাইভ করতে চাই:**
→ **[production.md](./production.md)** খুলে ধাপ ১ থেকে অনুসরণ করুন (~৩০ মিনিট, কোনো CMD লাগে না)।
লাইভ URL হবে `https://surjosangstha.onrender.com` — আলাদা ডোমেইন কিনতে হয় না।

**২–৩ মাস টেস্টিংয়ের পর পেইডে নিতে চাই:**
→ **[cpanel.md](./cpanel.md)** — ফ্রি Aiven থেকে ডাটা মাইগ্রেশনসহ সম্পূর্ণ পথ।
