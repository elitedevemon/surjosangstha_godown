# 🔔 Pusher ও Push নোটিফিকেশন সেটআপ

এই গাইডে দুইটা আলাদা জিনিস আছে —

| জিনিস | কী কাজ করে | কখন লাগে |
|---|---|---|
| **Pusher Channels** | অ্যাপ খোলা থাকা অবস্থায় রিয়েল-টাইম ডাটা (নতুন অর্ডার সাথে সাথে দেখা, লাইভ হেল্পডেস্ক, বেল ব্যাজ) | ঐচ্ছিক — না থাকলে ১৫–৪৫ সেকেন্ড পোলিং হয় |
| **Web Push (VAPID)** | অ্যাপ **বন্ধ থাকলেও** ফোন/কম্পিউটারের নোটিফিকেশন প্যানেলে পুশ পাঠায় | ঐচ্ছিক — কর্মী/কাস্টমার মোবাইলে নোটিশ পেতে |

দুটোই **ফ্রি টিয়ারে** চলে। দুটোই বন্ধ থাকলে অ্যাপের মূল কাজ বন্ধ থাকে না — শুধু তাৎক্ষণিকতা কম থাকে।

# অংশ ক — Pusher Channels

## ১. Pusher অ্যাকাউন্ট ও অ্যাপ

1. যান: **https://pusher.com** → **Sign up** (গুগল দিয়ে ফ্রি সাইনআপ)
2. ড্যাশবোর্ডে **Get Started / Channels** → **Create app**
3. ফর্ম:
   - **App name:** `surjosangstha`
   - **Cluster (region):** **ap2 = Mumbai** (বাংলাদেশের সবচেয়ে কাছে)
   - **Front-end:** JavaScript / React
   - **Back-end:** Node.js
4. **Create app** চাপুন

## ২. কী (Credentials) সংগ্রহ

আপনার অ্যাপ খুলে বাঁ পাশে **App Keys** মেনুতে যান। পাবেন:

```
app_id      = 1XXXXXX
key         = xxxxxxxxxxxxxxxxxxxx     ← এটি "public key"
secret      = xxxxxxxxxxxxxxxxxxxxxxxx
cluster     = ap2
```

> 🔒 **secret কখনো ব্রাউজারে/ক্লায়েন্টে দেবেন না** — শুধু সার্ভারে।

## ৩. কোথায় বসাবেন — দুই উপায়ের যেকোনো একটা

### উপায় A: এডমিন প্যানেল থেকে (সহজ, কোড ছাড়া)
1. এডমিন লগইন → **সেটিংস**
2. **রিয়েল-টাইম (Pusher) ও পুশ স্ট্যাটাস** কার্ড খুঁজুন
3. ফর্ম পূরণ করুন:
   - Pusher App ID
   - Key (public)
   - Secret
   - Cluster (`ap2`)
4. **সেভ করুন** → সাথে সাথে কার্যকর

### উপায় B: Environment Variables (প্রোডাকশনে বেশি নিরাপদ)

**লোকালে — `.env` ফাইলে:**
```env
PUSHER_APP_ID=1XXXXXX
PUSHER_KEY=xxxxxxxxxxxxxxxxxxxx
PUSHER_SECRET=xxxxxxxxxxxxxxxxxxxxxxxx
PUSHER_CLUSTER=ap2
NEXT_PUBLIC_PUSHER_KEY=xxxxxxxxxxxxxxxxxxxx
NEXT_PUBLIC_PUSHER_CLUSTER=ap2
```

**Render/Vercel-এ:** ড্যাশবোর্ড → Environment → উপরের ৬টি Key যোগ → Save → Redeploy

> 💡 `PUSHER_KEY` ও `NEXT_PUBLIC_PUSHER_KEY` একই মান; দুটোই লাগবে (একটা সার্ভার, একটা ব্রাউজারের জন্য)।

## ৪. Pusher চালু হয়েছে কিনা যাচাই
1. সাইট দুটো ট্যাবে খুলুন: একটায় এডমিন, অন্যটায় কর্মী/কাস্টমার
2. কর্মী প্যানেল থেকে একটি টেস্ট বিক্রয় এন্ট্রি দিন
3. এডমিন ট্যাবে রিফ্রেশ ছাড়াই **১–২ সেকেন্ডে** বেলে নোটিফিকেশন আসবে
4. এডমিন ড্যাশবোর্ডে **LIVE** ব্যাজ দেখাবে (AUTO ব্যাজের বদলে)

## ৫. Pusher ফ্রি টিয়ারের সীমা
- 200 কানেকশন একসাথে
- দিনে 200,000 মেসেজ (এই অ্যাপের জন্য প্রচুর)
- **দ্রষ্টব্য:** সিস্টেম অ্যাডাপটিভ — Pusher কানেক্টেড থাকলে পোলিং বন্ধ থাকে, তাই মেসেজ খরচ হয় না বললেই চলে।

# অংশ খ — Web Push (VAPID)

এটা দিয়ে অ্যাপ বন্ধ থাকলেও ফোন/কম্পিউটারে নোটিফিকেশন আসে (যেমন Messenger)।

## ১. VAPID কী জেনারেট করুন (দুই উপায়)

### উপায় A: অনলাইনে (CMD ছাড়া, সহজ)
1. যান: **https://vapidkeys.com** (অথবা https://web-push-codelab.glitch.me)
2. পেজ নিজেই দুইটা কী দেখাবে — কোনো তথ্য দিতে হয় না
3. কপি করুন:
   - **Public Key (VAPID public key)** — দীর্ঘ
   - **Private Key (VAPID private key)** — দীর্ঘ

### উপায় B: টার্মিনালে (একবার)
```bash
npx web-push generate-vapid-keys
```
আউটপুটে Public ও Private key দুটোই থাকবে।

## ২. Environment Variables

**লোকাল `.env`:**
```env
VAPID_PUBLIC_KEY=BNxxxxxxxx...দীর্ঘ স্ট্রিং...
VAPID_PRIVATE_KEY=xxxxxxxx...দীর্ঘ স্ট্রিং...
VAPID_SUBJECT=mailto:admin@yourdomain.com
```
> লোকাল ডেভেলপমেন্টে যদি মেইল না থাকে: `VAPID_SUBJECT=mailto:test@test.com`

**Render/Vercel:** পরিবেশ ভ্যারিয়েবলে একই তিনটি যোগ → Redeploy

> 🔑 কী একবার বানানোর পর আর বদলাবেন না — বদলালে পুরোনো সাবস্ক্রিপশন মরে যাবে।

## ৩. কাস্টমার/কর্মীর ডিভাইসে নোটিফিকেশন চালু করা

প্রতিটি ইউজার একবার নিজের ডিভাইস থেকে অনুমতি দেবে:

1. সাইটে লগইন করুন (কর্মী বা কাস্টমার হিসেবে)
2. উপরে ডানে **বেল (🔔)** আইকনে ক্লিক
3. **পুশ নোটিফিকেশন** কার্ড → **পুশ চালু করুন**
4. ব্রাউজার একটি অনুমতি চাইবে → **Allow / অনুমোদন**
5. **পুশ নোটিফিকেশন চালু** ব্যাজ দেখাবে ✅

সার্ভারে ডিভাইস স্বয়ংক্রিয়ভাবে সেভ হয় (`push_subscriptions` টেবিলে)।

## ৪. মোবাইল ডিভাইসভিত্তিক শর্ত

| ডিভাইস | কীভাবে চালু হয় |
|---|---|
| **Android** (Chrome/Edge) | সরাসরি কাজ করে — শুধু Allow দিন |
| **Desktop** (Chrome/Firefox/Edge) | সরাসরি কাজ করে |
| **iPhone (iOS 16.4+) Safari** | আগে সাইটটিকে **Home Screen-এ যোগ (Add to Home Screen)** করতে হবে → তারপর Share মেনু → **Add to Home Screen**; তারপর সাইট খুলে বেল → পুশ চালু |
| **iPhone-এ PWA হিসেবে** | Add to Home Screen করলে অ্যাপের মতো ফুল-স্ক্রিন আইকন পাওয়া যায় |

## ৫. টেস্ট
1. একটি ডিভাইসে কাস্টমার লগইন করে পুশ Allow করুন
2. এডমিন প্যানেল থেকে একটি অর্ডার গ্রহণ/হেল্পডেস্ক রিপ্লাই দিন
3. সেই ডিভাইসে ওয়েবসাইট বন্ধ থাকলেও নোটিফিকেশন আসবে (ব্রাউজার খোলা থাকতে হবে — নোটিফিকেশন OS দেখায়)

> 📌 Web Push-এর জন্য **HTTPS লাগে** — লোকালে `http://localhost:3000` কাজ করে (এটা ব্রাউজারের ব্যতিক্রম), কিন্তু লাইভ সাইট অবশ্যই HTTPS হতে হবে (Render/Vercel-এ স্বয়ংক্রিয়)।

# অংশ গ — রিয়েল-টাইম আর্কিটেকচার (বোঝার জন্য)

## নোটিফিকেশন কীভাবে যায়
```
কর্মী বিক্রয় এন্ট্রি দেয়
        │
        ▼
সার্ভার: notifications টেবিলে সেভ
        │
        ├── Pusher চালু থাকলে ──▶ ওয়েবসকট ইভেন্ট (১ সেকেন্ডে লাইভ)
        │
        └── Web Push (VAPID)   ──▶ অ্যাপ বন্ধ থাকা ডিভাইসে OS নোটিফিকেশন
```

## ব্রাউজার বেল আইকনের কৌশল
- **Pusher কানেক্টেড:** নোটিফিকেশন সাথে সাথে আসে; ব্যাকগ্রাউন্ড পোলিং বন্ধ থাকে
- **Pusher নেই:** ট্যাব খোলা ও দৃশ্যমান থাকলে প্রতি **১৫ সেকেন্ডে** নতুন নোটিফিকেশন চেক
- **ট্যাব লুকানো/অফলাইন:** পোলিং থেমে থাকে; আবার সক্রিয় হলে সাথে সাথে চেক
- **ডাটাবেসে সবসময় সেভ হয়** — কোনো নোটিফিকেশন হারায় না

## কোন চ্যানেল শোনে কে
- এডমিন: `role-admin`
- কর্মী: `user-<তার ID>` + `role-employee`
- কাস্টমার: `user-<তার ID>` + `role-customer`

## ইভেন্ট
- `notification` — নতুন নোটিফিকেশন (বেল ব্যাজ, সাউন্ড)
- `data-update` — ড্যাশবোর্ড/টেবিল রিফ্রেশ সংকেত

# 🛠️ সমস্যা সমাধান

## Pusher
| সমস্যা | সমাধান |
|---|---|
| ব্যাজ দেখায় AUTO, LIVE নয় | কী ভুল/বাদ পড়েছে। সেটিংসে App ID/Key/Secret/Cluster মিলিয়ে দেখুন; ব্রাউজার F12 → Console-এ Pusher error দেখুন |
| সাথে সাথে আসে না, ১৫ সেকেন্ড পরে | Pusher কানেকশন সফল হয়নি — cluster `ap2` ঠিক আছে কিনা দেখুন |
| সার্ভার লগে `Pusher app key invalid` | PUSHER_KEY/PUSHER_SECRET উল্টে গেছে কিনা দেখুন |
| ফ্রি কানেকশন লিমিট | স্বাভাবিক ব্যবহারে সমস্যা হবে না; প্রয়োজনে পেইড |

## Web Push
| সমস্যা | সমাধান |
|---|---|
| Allow চাইতে আসে না | HTTPS-এ আছেন তো? (localhost ছাড়া HTTP-তে কাজ করে না); iOS-এ Home Screen-এ যোগ করুন |
| Allow দেওয়ার পরেও নোটিফিকেশন আসে না | ব্রাউজার/OS-এর নোটিফিকেশন সেটিংস চেক; VAPID কী পরিবর্তন হয়নি তো? |
| আইফোনে কোনো অপশনই নেই | iOS 16.4+ লাগবে এবং সাইট আগে Add to Home Screen করতে হবে |
| নতুন ডিভাইস পায় না | ওই ডিভাইসে বেল → Push toggle আবার চেক; VAPID_PRIVATE_KEY একই কিনা |
| `VAPID claims mismatch` | Public ও Private কী জোড়া মেলেনি — একই generate থেকে নিন |

## লাইভে কনফিগ বদলানোর পর
1. সেটিংস সেভ হলে ৩০ সেকেন্ডের মধ্যে সার্ভার কনফিগ রিলোড করে
2. env ভ্যারিয়েবল বদলালে **Redeploy/Restart** বাধ্যতামূলক
3. পুশ কী বদলালে ইউজারদের আবার Allow করাতে হতে পারে
